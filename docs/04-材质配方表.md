## 1. 配方总表

单位说明：`H` = `refractionHeight`，`A` = `refractionAmount`，都是 **dp 量级、实际传 px（`.dp.toPx()`）**。
`CA` = `chromaticAberration`，`DE` = `depthEffect`。

| # | 配方 | 上游出处 | effects（strict order） | H / A | CA | DE |
|---|---|---|---|---|---|---|
| 1 | **Button** | `components/LiquidButton.kt` | `vibrancy()` → `blur(2.dp)` → `lens` | 12 / 24 | ✗ | ✗ |
| 2 | **BottomBar** | `components/LiquidBottomTabs.kt`（栏背景） | `vibrancy()` → `blur(8.dp)` → `lens` | 24 / 24 | ✗ | ✗ |
| 3 | **selectionIndicator(progress)** | `components/LiquidBottomTabs.kt`（移动指示器） | `lens` | 10×p / 14×p | ✓ | ✗ |
| 4 | **toggleKnob(progress)** | `components/LiquidToggle.kt`（开关丸粒） | `blur(8.dp ×(1−p))` → `lens` | 5×p / 10×p | ✓ | ✗ |
| 5 | **sliderKnob(progress)** | `components/LiquidSlider.kt`（滑块丸粒） | `blur(8.dp ×(1−p))` → `lens` | 10×p / 14×p | ✓ | ✗ |
| 6 | **dialog(isLightTheme)** | `destinations/DialogContent.kt` | `colorControls(b, 1.5)` → `blur(16/8.dp)` → `lens` | 24 / 48 | ✗ | **✓** |
| 7 | **NavigationBar** | `tutorials/glass-bottom-bar` | `vibrancy()` → `blur(4.dp)` → `lens` | 16 / 32 | ✗ | ✗ |
| 8 | **BottomSheet** | `tutorials/glass-bottom-sheet` | `vibrancy()` → `blur(4.dp)` → `lens` | 24 / 48 | ✗ | **✓** |
| 9 | **Card** | `destinations/LazyScrollContainerContent.kt` | `vibrancy()` → `lens`（**无 blur**） | 16 / 32 | ✗ | ✗ |
| 10 | **controlCenterItem(progress)** | `destinations/ControlCenterContent.kt` | `vibrancy()` → `lens` | 24×p / 48×p | ✗ | **✓** |

源码原文：

```kotlin
object GlassMaterials {
    val Button = { vibrancy(); blur(2f.dp.toPx()); lens(12f.dp.toPx(), 24f.dp.toPx()) }
    val BottomBar = { vibrancy(); blur(8f.dp.toPx()); lens(24f.dp.toPx(), 24f.dp.toPx()) }

    fun selectionIndicator(progress: Float) = {
        lens(10f.dp.toPx() * progress, 14f.dp.toPx() * progress, chromaticAberration = true)
    }
    fun toggleKnob(progress: Float) = {
        blur(8f.dp.toPx() * (1f - progress))
        lens(5f.dp.toPx() * progress, 10f.dp.toPx() * progress, chromaticAberration = true)
    }
    fun sliderKnob(progress: Float) = {
        blur(8f.dp.toPx() * (1f - progress))
        lens(10f.dp.toPx() * progress, 14f.dp.toPx() * progress, chromaticAberration = true)
    }
    fun dialog(isLightTheme: Boolean) = {
        colorControls(brightness = if (isLightTheme) 0.2f else 0f, saturation = 1.5f)
        blur(if (isLightTheme) 16f.dp.toPx() else 8f.dp.toPx())
        lens(24f.dp.toPx(), 48f.dp.toPx(), depthEffect = true)
    }
    val NavigationBar = { vibrancy(); blur(4f.dp.toPx()); lens(16f.dp.toPx(), 32f.dp.toPx()) }
    val BottomSheet = { vibrancy(); blur(4f.dp.toPx()); lens(24f.dp.toPx(), 48f.dp.toPx(), true) }
    val Card = { vibrancy(); lens(16f.dp.toPx(), 32f.dp.toPx()) }
    fun controlCenterItem(progress: Float) = {
        vibrancy(); lens(24f.dp.toPx() * progress, 48f.dp.toPx() * progress, depthEffect = true)
    }
}
```

## 4. 三张速查表：改哪个参数、往哪改

### 4.1 尺寸 → 强度（最重要的一张表）

**折射强度必须与组件尺寸成正比。** 同一组 `lens` 参数，放在 56dp 按钮上像水滴，放在 340dp 面板上就像没折射。

| 组件视觉面积 | 推荐 H / A | 例子 |
|---|---|---|
| 极小（丸粒、指示器，≈40×24） | 5 / 10 ～ 10 / 14 | 开关丸粒、分段滑块 |
| 小（按钮、芯片，高度 32~48） | 12 / 24 | `Button` |
| 中（导航栏、搜索框、列表项） | 16 / 32 | `NavigationBar`、`Card` |
| 中（底栏，64 高全宽） | 24 / 24 | `BottomBar` |
| 大（面板、弹窗、控制中心） | 24 / 48 | `dialog`、`BottomSheet`、`controlCenterItem` |

### 4.2 想要什么感觉 → 改什么

| 想要 | 改 | 方向 |
|---|---|---|
| 玻璃更"厚"、更像一滴水 | H 与 A **同比例**加 | `16/32 → 24/48` |
| 折射带更宽（整块都在扭） | 只加 H | `16/32 → 32/32` |
| 背景更雾 | 加 `blur` | `4 → 8 → 16` |
| 玻璃更"实" | 加深 `onDrawSurface` | `White 5% → 35%`（**上限**） |
| 边缘亮光更强 | `highlight.copy(alpha = 1f)` | `0.5 → 1.0` |
| 更像"有厚度" | 加 `innerShadow(radius, alpha)` | 仅在按下时 |
| 更"果冻" | 加 `depthEffect` | 只给大面积 |

### 4.3 主题 → 参数差异

| 参数 | 浅色 | 深色 | 为什么 |
|---|---|---|---|
| `colorControls.brightness` | `0.2` | `0` | 浅色背景亮，需提亮；深色再提亮会过曝 |
| `colorControls.saturation` | `1.5` | `1.5` | 都要提饱和 |
| `blur`（dialog） | `16.dp` | `8.dp` | 深色场景模糊过大反而糊成一片 |
| `onDrawSurface` | 偏白 | 偏暗容器色 | 见 §3 的 `barContainer` / `dialogContainer` |

## 5. 反查：上游还有哪些参数我没抄？

本仓库只抄了"展示型组件"用得到的配方。上游 Catalog 里还有若干组件（例如更复杂的弹层组合、
导航/教程页专用材质），本仓库没有使用。如果你要扩展：

1. 去上游仓库 `app/src/commonMain/kotlin/com/kyant/backdrop/catalog/` 找对应文件；
2. 抄它的 `effects` 代码块**原文**；
3. 在 [GlassMaterials.kt](../LiquidGlassShowcase/app/src/main/java/com/liquidglass/showcase/core/glass/GlassMaterials.kt) 加一个 val/fun，**注释里写上出处文件名**；
4. 回到本章 §1 补一行。

**不要凭感觉发明配方。** 上游已经把光学参数调到"苹果味"了，你的直觉大概率不如它。

## 6. 推导新配方的规则（必须遵守）

```
第 1 步  定尺寸档位         → 从 §4.1 找到 H/A 起点
第 2 步  定"雾度"           → blur：小控件 2~4，中 8，大 16
第 3 步  定"厚度感"         → 大面积才考虑 depthEffect = true
第 4 步  定"是否动态"       → 动态（按下/拖动）才开 chromaticAberration
第 5 步  定"染色"           → onDrawSurface ≤ 35%（弹窗类除外，可到 60%）
第 6 步  定高光/阴影        → 有方向感用 Default；大面积用 Ambient 或 Plain
第 7 步  保持比例           → A ≈ 2 × H（上游所有配方都满足这个关系）
```

**三条硬约束：**

1. `effects` 书写顺序永远是 `颜色 → blur → lens`；
2. 任何长度参数必须 `.dp.toPx()`；
3. 静止态不开色散。

**增量调参法（推荐）**：一次只改一个参数，改完截图对比。同时改两个，
你永远不知道是哪个起了作用——这是调参最大的时间黑洞。

## 7. 材质的"克制"程度阶梯

苹果的设计里，材质是**分层使用**的：越靠上、越临时的东西，玻璃越"实"；越基础的东西，玻璃越"透"。

```
最透 ────────────────────────────────────────────────► 最实

Card            BottomBar      NavigationBar     Dialog / Sheet      ControlCenter
16/32           24/24          16/32             24/48 + DE          24/48 + DE
无 blur          blur 8         blur 4            blur 8~16          无 blur
White 22%       container      White 50%         dialogContainer     Black 5%
                                        ↑                            ↑
                                  临时、强暗示                  强暗示、但极克制

丸粒类（Toggle/Slider/Indicator）：5/10 ~ 10/14 —— 最小折射、最强调"动态"
```

**常见错误：把丸子类的小折射参数用在大面板上，或者把面板的大折射参数用在按钮上。**
折射强度是**跟着尺寸走**的，这是 §4.1 存在的理由。

## 8. 本章小结

- 12 个配方（含 4 个带 `progress` 的动态配方）= 本仓库全部材质，全部照抄上游。
- 一个材质 = `shape` + `effects` + `onDrawSurface` + `highlight/shadow`，四件套缺一不可。
- **H/A 跟尺寸走，A ≈ 2H，顺序不能乱，长度必须 toPx，动态才开色散。**
